# Directional Sound and Gaze

초지향성 스피커는 moving sweet spot이나 anamorphic system에서 나중에 파생된 아이디어가 아님

작품 초반부터 시각 시스템과 병렬로 생각했던 요소

관객이 작품의 시선을 느끼게 하려면
반드시 화면을 보고 눈을 마주치는 방식만 있을 필요는 없다고 생각

사람도 상대방을 직접 보고 있지 않은 상황에서
누군가 자신을 바라보고 있는 것 같은 감각을 느낄 때가 있음

그래서 시각에서는 작품의 시점이 관객을 향하게 만들고

소리에서는 공간 전체에 퍼지는 일반적인 스피커 대신
특정한 방향을 가진 소리가 관객에게 도달하게 만드는 방법을 생각

두 시스템은 처음부터 같은 질문을 서로 다른 감각에서 다루는 병렬적인 방향

* visual gaze

  * 관객의 위치에 따라 작품의 viewpoint를 변화
  * 작품의 시선이 관객을 향하도록 만드는 방식 탐색

* auditory gaze

  * 특정한 관객 방향으로만 소리를 전달
  * 화면을 직접 보고 있지 않아도 작품의 방향성을 느낄 수 있는 방식 탐색

이후 시각 쪽에서는 anamorphosis와 moving sweet spot이라는 구체적인 방법을 발견했고

음향 쪽에서는 parametric speaker를 직접 제작하는 방향으로 발전

두 방식이 나중에 하나의 시스템으로 합쳐지기는 하지만
한쪽에서 다른 쪽이 파생된 것은 아님

처음부터

보이는 시선과
보이지 않는 방향성을 가진 소리

두 가지 방법으로 같은 문제를 동시에 탐색
