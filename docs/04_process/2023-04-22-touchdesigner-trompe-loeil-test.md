# 2023.04.22 TouchDesigner Trompe-l'oeil Test

시점에 따라 다르게 보이는 트롱프뢰유를 실제로 구현

이전에 TouchDesigner에서 카메라 위치에 따라 화면이 다르게 보이는 방식으로 테스트했는데
실제로 관객 위치에 맞춰 변화하는 형태가 가능한지 확인

SweetSpot previz 참고

하나의 이미지나 영상이 아니라
관찰자의 위치가 바뀌면 같은 공간 안에 있는 오브젝트가 다르게 보이는 방식

프로젝션이나 디스플레이가 단순히 이미지를 출력하는 게 아니라
관객의 시점에 맞춰 가상의 공간을 생성하는 방식으로 접근

TouchDesigner에서 카메라 위치값을 변경하면서
시점 변화에 따른 아나모픽 이미지 변화를 테스트

결과적으로 특정 시점에서는 형태가 맞아 보이고
다른 위치에서는 왜곡되어 보이는 트롱프뢰유 구현 가능 확인
