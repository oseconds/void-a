# 2023.06.09 Parametric Speaker Prototype

## 초지향성 스피커 제작 시작

이전까지는 회로나 제작 사례를 계속 찾아보면서
직접 만드는게 가능한지 확인하는 과정이었다면

이때부터 실제 부품을 주문하고 제작 시작

NE555를 이용한 초음파 반송파 생성 회로와
L293D 드라이버를 이용한 구동 회로 구성

20V 입력에서 7805로 5V를 만들고
오디오 신호를 초음파에 실어서 출력하는 구조

초음파 트랜스듀서 어레이도 같이 제작

처음에는 제대로 동작하는지만 확인하는 단계라
부품 배치부터 하나씩 맞춰보면서 진행

## 남아있는 자료

- 제작 초기 사진
- 회로도(Schematic)
- 부품 배치 사진
