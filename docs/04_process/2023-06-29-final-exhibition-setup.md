# 2023-06-29 Final Exhibition Setup

초기 제작 과정에서는 STM32와 HW-131 전원 모듈을 활용하여
초음파 스피커 변조 회로를 테스트했으나,
실제 전시 환경 적용 과정에서 전원 공급이 분산되고 출력 안정성이 떨어지는 문제가 있어
해당 구성을 제거하고 외부 전원 공급 방식으로 변경하였다.

최종적으로는 별도 DC 파워서플라이를 사용해 각 회로에 필요한 전압을 직접 공급하는 방식으로 구성하였다.

## Final Power Configuration

- CH1: 16.9V / 0.11A (C.V. Mode)
  - L298N 기반 초음파 트랜스듀서 구동 회로

- CH2: 3.4V / 0.01A (C.V. Mode)
  - 555 기반 변조 회로 및 저전압 회로

초기에는 여러 전원 모듈과 보드를 거치는 방식으로 구성했으나,
전시 환경에서는 안정적인 출력과 관리 편의성을 위해
필요한 전압을 직접 공급하는 구조로 단순화하였다.
