# 2023-06-29 Final Exhibition Setup

실제 전시 공간에서 초지향성 스피커 시스템의 최종 셋업 진행

## Power Supply Configuration

Protek PL-3003T DC Regulated Power Supply를 사용해  
출력부와 제어부의 전원을 분리하여 공급

최종 전시 환경에서 사용한 전원 조건:

- CH1: 16.9V / 0.11A (C.V. Mode)
  - L298N 드라이버 및 초음파 트랜스듀서 출력 회로 전원

- CH2: 3.4V / 0.01A (C.V. Mode)
  - STM32 제어 보드 전원

## Final Adjustment

이전 테스트 과정에서 배터리, USB 전원, 파워서플라이 등 다양한 전원 환경에 따라  
초음파 변조 상태와 출력 특성이 달라지는 것을 확인

실제 전시 공간에서는 안정적인 출력과 제어를 위해  
파워서플라이를 사용하고 최종 전압 조건을 설정
