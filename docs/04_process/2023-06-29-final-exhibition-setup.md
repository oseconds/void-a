# 2023-06-29 Final Exhibition Setup

실제 전시 공간에서 초지향성 스피커 시스템 최종 셋업 진행

## Power Supply Configuration

초기 프로토타입에서는 HW-131 전원 모듈과 STM32 보드를 활용해
제어 및 변조 회로를 테스트했으나,
최종 구성에서는 불필요한 제어부를 제거하고 회로를 단순화하여
파워서플라이 기반으로 전원을 공급

최종 사용 조건:

- CH1: 16.9V / 0.11A (C.V. Mode)
  - L298N 드라이버 및 초음파 트랜스듀서 출력 회로

- CH2: 3.4V / 0.01A (C.V. Mode)
  - 555 변조 회로 등 저전압 회로 전원

초기 테스트 과정에서 전원 조건에 따라 변조 특성과 출력이 변화하는 것을 확인하여,
실제 전시 환경에서는 파워서플라이를 사용해 안정적인 동작 조건을 설정
