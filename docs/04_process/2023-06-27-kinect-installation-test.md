# 2023-06-27 Azure Kinect Installation Test

실제 전시 공간에서  
Azure Kinect 설치 위치와 인식 환경 테스트 진행

## Space Setup

전시 공간에 멀티 모니터와 PC 환경을 구성하고  
모니터 상단에 Azure Kinect를 설치해 관객 인식 테스트 준비

## Kinect Test

Azure Kinect의 깊이 정보를 활용해  
관객의 위치와 공간 정보를 인식하기 위한 테스트 진행

실제 공간에서는 카메라 설치 높이와 방향에 따라  
인식 범위와 결과가 달라지기 때문에  
설치 위치를 조정하며 최적 조건 확인

이후 TouchDesigner와 연동하여  
관객 위치 변화에 따른 프로젝션 변화와 실시간 반응 구현을 위한 기반 구축

## 이미지 메모

- 실제 전시 공간 내부
- 모니터 상단에 설치된 Azure Kinect
- PC 및 디스플레이 연결 상태
