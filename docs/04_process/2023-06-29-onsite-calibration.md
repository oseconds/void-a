# 2023.06.29 On-site Calibration

## 전시장 환경에서 Kinect 캘리브레이션

실제 전시장에 설치하면서 Kinect 인식 범위와 시점을 다시 맞춤

작업하면서 lookup.4.toe 파일 생성

스크린 위치와 크기에 맞춰 Screen Xform 값도 같이 조정

실험실에서 테스트할 때와는 다르게
실제 공간에서는 프로젝션 위치, 스크린 크기, 관객 동선에 따라 값이 많이 달라져서
현장에서 하나씩 맞춰가는 과정

이 시점부터는 새로운 기능을 만드는 것보다
전시장 환경에 맞게 전체 시스템을 안정적으로 동작하도록 조정하는 작업 위주
