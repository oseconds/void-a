# 2023.05.08 Directional Sound Research

## 공간에서 소리의 방향을 만드는 방법

초지향성 스피커를 작품에 사용할 예정이라
소리를 특정 방향으로 전달하는 여러 방법 같이 찾아봄

이번에는 Rear Delay Array 방식 참고

뒤쪽 스피커에 딜레이를 주면
후면에서는 위상이 상쇄되고
앞쪽에서는 같은 위상으로 합쳐져 음압이 올라가는 구조

결국 같은 스피커라도
배치와 시간차만으로 소리가 전달되는 방향을 어느 정도 제어할 수 있다는 점이 흥미로웠음

작품에서는 초지향성 스피커를 사용할 예정이었지만
공간에서 소리를 어떻게 제어하는지에 대한 기본 원리도 같이 정리

이후 스피커 방향 제어와 공간 배치 고민할 때 참고
