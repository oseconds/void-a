변조 조건 테스트

참고한 스케메틱을 기준으로 회로를 구성했지만
실제 제작 환경에서는 입력 전력, 출력부 구성, 초음파 어레이 조건에 따라
같은 저항값을 사용해도 변조 상태와 출력 특성이 달라짐

그래서 정해진 값을 그대로 사용하는 것보다
직접 저항값을 변경해가며 범위를 좁혀가고
지향성을 유지하면서 최대한 큰 출력이 나오는 조건을 찾는 방식으로 조정

STM32를 기반으로 555 타이머와 L298N 드라이버를 연결해
오디오 입력이 초음파 반송파에 변조되어 출력되는 과정을 확인

L298N은 원래 모터 제어용 드라이버지만
초음파 트랜스듀서 어레이를 구동하기 위한 출력부로 활용

저항 구성에 따라 변조 특성과 출력 크기가 계속 달라졌고
여러 조합을 테스트하면서 실제 사용할 조건을 찾아감

이미지 메모

- 브레드보드 위 변조 회로 구성
- 저항값 변경하며 테스트한 회로 상태
- L298N 및 초음파 어레이 연결 상태
