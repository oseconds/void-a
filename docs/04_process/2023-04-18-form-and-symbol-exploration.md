# 2023.04.18 작품 형태 및 표현 방식 고민

하나의 온전한 작품으로 보이기 위해 어떤 요소가 추가적으로 필요할지 생각

처음에는 눈이라는 형태를 그대로 사용하는 방향을 생각했는데
너무 직접적인 상징일 수도 있을 것 같음

눈을 의미하지만 직접적으로 눈이라고 보여주지 않는 방법?

예를 들면 입자들이 모여있는 구 형태를 보고 눈이라고 인식하는 것처럼
형태 자체가 아니라 관객이 가지고 있는 경험이나 기호를 통해 눈으로 해석하게 만드는 방식

눈이라는 기호를 그대로 보여주는 것보다
어떤 형태를 보고 관객이 스스로 의미를 부여하게 하는 방향

추상적인 형태
비유적인 형태
상징화된 형태

어떤 방식이 응시라는 개념을 더 잘 전달할 수 있을지 고민

작품이 관객의 데이터를 읽는 방식

단순히 위치값을 받아서 화면을 변화시키는 것?
그럼 인터랙티브한 작품은 될 수 있지만 응시라는 개념과 연결되는지는 고민

어떤 데이터를 읽어야 작품이 관객을 바라본다는 느낌을 줄 수 있을까
