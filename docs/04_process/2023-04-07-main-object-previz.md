# 2023.04.07 메인 오브젝트 형태 프리비즈

응시라는 개념을 실제 공간에서 어떤 형태로 보여줄 수 있을지 메인 오브젝트 형태 탐색

처음에는 눈이라는 형태 생각

보는 것과 보여지는 것을 가장 직관적으로 표현할 수 있는 기호라서

근데 너무 직접적인가?

그냥 현실적인 안구 형태로 만들면 감시 카메라나 파놉티콘 같은 의미로만 읽힐 수도 있을 것 같음

그렇다고 완전히 추상적인 형태로 가면 관객이 "무언가가 나를 보고 있다"는 느낌을 바로 받을 수 있을까?

눈이라는 요소는 유지하면서 조금 더 존재처럼 느껴지는 방향 생각

만화나 판타지에서 나오는 눈을 가진 캐릭터 같은 느낌
현실에 없는 형태지만 하나의 개체처럼 느껴지는 방향

큐브 형태의 디스플레이 안에 구 형태의 오브젝트가 있고
그 안에 눈의 요소가 들어가는 형태로 프리비즈 제작

미드저니로 여러 형태 생성하면서 분위기와 형태 확인

당시에는 생성형 이미지가 지금처럼 결과물을 제작하는 용도라기보다는
머릿속에 있는 형태를 빠르게 확인하는 프리비즈 도구로 활용

눈이라는 기호를 그대로 사용할지
아니면 눈에서 파생된 다른 형태로 갈지는 계속 고민

결국 중요한 건 눈을 보여주는 게 아니라
관객이 어떤 존재와 마주하고 있다는 감각을 만드는 것
