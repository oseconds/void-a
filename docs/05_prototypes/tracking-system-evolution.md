# Tracking System Evolution

## HTC Vive Tracking Experiment

Early research explored HTC Vive-based positional tracking.

The purpose was not VR immersion, but acquiring the viewer's position and connecting it to the virtual viewpoint.

However, the necessity of holding or wearing tracking devices introduced another relationship:
the viewer appeared to control the artwork through an external object.

## Kinect Direction

Kinect was explored as an alternative because it allowed invisible observation.

Without requiring any visible interaction device, the system could create the impression that the virtual object was already aware of the viewer's presence.

This shifted the interaction model:

Viewer controls artwork
→
Artwork perceives viewer
